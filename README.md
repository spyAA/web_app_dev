# Pelican on a Bicycle (WebXR)

3D pelican riding a bicycle, built with **Three.js** and **WebXR**.

## Run

```bash
npm install
npm run dev
```

Open the printed local URL. Drag to orbit, scroll to zoom. On a VR headset browser, use **Enter VR**.

## What’s inside

- Procedural pelican + bicycle meshes (`src/pelicanBike.js`)
- Pedaling / track loop animation
- Desktop orbit camera
- WebXR immersive VR (`VRButton` + controller grips)
